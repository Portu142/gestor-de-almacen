# Capturas de pantalla

Estas imágenes se muestran en el README. Para añadirlas:

1. Arranca la app (`npm run seed` + `npm run dev` en backend y frontend).
2. Abre <http://localhost:5173> y prepara la pantalla que quieras capturar.
3. Captura a **1280×800** (o similar). Sin marco del navegador si puedes.
4. Guárdala aquí con estos nombres exactos:

| Archivo | Pantalla |
|---|---|
| `resumen.png` | Dashboard (tarjetas + reposiciones pendientes) |
| `inventario.png` | Inventario con el formulario de alta abierto |
| `movimientos.png` | Movimientos con el historial y el formulario |

5. Sube los cambios y el README las mostrará automáticamente.

> Consejo: si los datos de ejemplo son los de `npm run seed`, las capturas
> quedarán siempre iguales y consistentes entre sí.
